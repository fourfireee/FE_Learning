# 讲解前端学习专题

这个 skill 帮助把本仓库的**笔记**（`docs/`）和**配套示例**（`examples/`）结合起来，给用户做一次有重点的专题讲解。

## 仓库约定

- `docs/NN-*.md` 是按编号组织的知识笔记。
- `examples/NN-*/` 是对应编号的可运行示例。
- 编号一一对应（例如 `docs/02-css.md` ↔ `examples/02-css-layout-and-animation/`）。

## 步骤

1. **定位专题**：根据用户说的关键词或编号，匹配到对应的 `docs/NN-*.md` 和 `examples/NN-*/`。若不确定，先列出所有可选编号让用户挑。
2. **读笔记**：读取该 `docs/NN-*.md`，提炼 3-5 个核心知识点。
3. **看示例**：浏览对应 `examples/NN-*/` 的关键文件，找出笔记中知识点在代码里的具体落点。
4. **串讲**：用「概念 → 代码在哪体现 → 容易踩的坑」的结构输出，每个知识点都指到具体文件和行号。
5. **追问**：结尾给出 1-2 个可以深入的方向，问用户要不要继续。

## 输出要求

- 中文讲解，简洁有重点，不要逐行翻译代码。
- 引用文件用可点击的相对路径格式，例如 `docs/02-css.md`、`examples/02-css-layout-and-animation/index.html:30`。
- 如果笔记和示例不一致，明确指出来。
